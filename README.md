# 🐾 Pet Adoption Portal

A full-stack web application that connects pet lovers with pets in need of a home. The platform allows users to browse available pets, submit adoption requests, and manage pet listings through a secure and user-friendly interface.

## 📖 Overview

The Pet Adoption Portal aims to simplify the pet adoption process by providing a centralized platform where shelters, pet owners, and adopters can interact efficiently. Users can explore pet profiles, view detailed information, and apply for adoption online.

## ✨ Features

### 👤 User Features
- User Registration & Login
- Secure Authentication
- Browse Available Pets
- Search and Filter Pets
- View Detailed Pet Profiles
- Submit Adoption Requests
- Track Adoption Status
- Manage User Profile

### 🐕 Pet Management
- Add New Pet Listings
- Update Pet Information
- Upload Pet Images
- Mark Pets as Adopted
- Delete Pet Listings

### 🛠️ Admin Features
- Dashboard for Managing Users
- Approve/Reject Adoption Requests
- Manage Pet Listings
- View Adoption Statistics
- Monitor Platform Activity

## 🔄 Workflow

1. User registers or logs in.
2. Browse available pets.
3. View pet details.
4. Submit adoption request.
5. Admin reviews request.
6. Pet status updated after approval.
